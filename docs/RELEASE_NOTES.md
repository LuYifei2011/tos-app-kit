# 0.3.0

- 新增可选 Go `files` 子包，显式注册后提供当前 TOS 用户的共享目录、完整分页列表与路径复核；支持应用目录范围、超时、条目限制及会话隔离。
- `createTosApp({ files: true })` 使用默认 HTTP 文件适配器，复用应用 API 客户端；支持自定义路由和 provider，省略或关闭时不启用文件服务。
- 新增 `TosPathInput`：路径文本框与文件对话框按钮，支持字符串绑定、直接编辑开关、禁用状态及打开/保存文件或文件夹。
- 新增 `TosFileDialog`：打开 NAS 文件、选择文件夹、保存文件/文件夹目标，支持多选、目录导航、名称与类型筛选和同名目标确认。
- core 提供可注入的 `TosFileProvider` 和独立选择控制器，包含路径复核、异步取消与过期响应隔离；应用通过自己的后端执行文件操作。
- 对话框接入中英翻译、浅深主题和窄屏样式；示例、接口文档及状态测试同步补齐。
- 文件对话框采用共享文件夹侧栏与详情列表，支持导航历史、面包屑、路径输入、单击选择、Ctrl/Meta 切换、Shift 范围及键盘操作；桌面布局适配 960×600 应用区域，窄屏提供触摸进入目录和路径编辑入口。
- `TosFileEntry` 新增可选大小与修改时间，控制器新增 `setSelection(paths)`；名称筛选或类型切换清空选择并保留保存名称。同名目标使用独立确认层，取消后保留名称与选择并恢复焦点。

TOS 目录接口按当前登录用户授权，可能与应用后端服务账号权限不同；需要后端处理所选文件时，建议使用按后端实际权限提供目录的自定义文件服务。

# 0.2.0

- 新增 TosAppShell，提供 41px 标题栏、标题与图标插槽、附加内容和可配置滚动的内容区。
- 标题栏预留 TOS 窗口控件空间，长标题截断，窄屏采用整页滚动。
- 独立示例接入应用框架；浏览器 core 与 Go 的运行行为保持原有实现。
- 浏览器包和 Go module 使用同一发布版本；应用可以通过固定版本 URL 和 Go 标签安装。

# 0.1.0

首次发布 TOS 应用公共库：

- `tos-app-core`：浏览器 API、诊断、偏好设置、国际化和 Vue 上下文。
- `tos-app-ui-kit`：主题、基础样式、语言主题设置和连接诊断组件。
- Go module：凭据及来源检查、平台验证接口、HTTP、数据目录和服务生命周期。

浏览器包提供编译后的 ESM 与类型声明，附件可直接交给 npm 安装。Go module 使用 `go/v0.1.0` 标签。
