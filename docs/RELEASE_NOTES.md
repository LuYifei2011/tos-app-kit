# 0.2.0

- 新增 TosAppShell，提供 41px 标题栏、标题与图标插槽、附加内容和可配置滚动的内容区。
- 标题栏预留 TOS 窗口控件空间，长标题截断，窄屏采用整页滚动。
- 独立示例接入应用框架；浏览器 core 与 Go 的运行行为保持原有实现。
- 浏览器包和 Go module 使用同一发布版本；应用可以通过固定版本 URL 和 Go 标签安装。

# 0.1.0

首次发布 TOS 应用公共库：

- `tos-app-core`：浏览器 API、诊断、偏好设置、国际化和 Vue 上下文。
- `tos-app-ui-kit`：主题、基础样式、语言主题设置和连接诊断组件。
- Go module：凭据及来源检查、平台验证接口、HTTP、数据目录和服务生命周期。

浏览器包提供编译后的 ESM 与类型声明，附件可直接交给 npm 安装。Go module 使用 `go/v0.1.0` 标签。
