# 界面规范

界面用于 TOS 桌面内的文件管理，重点是目录、规则和文件名变化。采用 TOS 的紧凑窗口布局、系统字体和蓝色选中态。

默认窗口为 960×600，标题栏固定 41px，左侧规则区宽 280px，右侧预览使用剩余空间。窄屏按规则、预览顺序排列。TOS 提供实际窗口标题栏及最小化、最大化和关闭按钮。

共享文件夹是目录列表的根层级，路径导航位于文件列表上方。多规则通过有序标签切换，一次显示一条规则的字段。主要动作固定在规则区底部，帮助和语言主题设置位于左下角。

字号使用 12、13、14、16px，控件圆角 4px。桌面表单高 32px，文件行高 34px；窄屏控件及文件行高 44px，虚拟列表使用相同行高。浅深主题共用布局和语义颜色变量。

蓝色表示选择和主要操作，错误同时使用图形与文字。冲突原因显示在新名称下方。应用、窗口内图标和 favicon 共用自写的重命名符号，仅确认对话框使用投影。

保持原生表单、可见键盘焦点、规则标签方向键导航和对话框 Escape 关闭。中英切换覆盖辅助标签、校验原因和任务结果；英文允许换行，文件名与用户输入保留原样。

控件焦点使用与边缘重合的 2px 实线，不占据额外布局空间。路径输入、目录搜索和路径编辑由外层容器绘制完整焦点线；路径选择按钮以选中底色区分键盘焦点所在位置。主要按钮使用内侧浅色焦点线。文件行通过蓝色底色表示选中，键盘焦点独立绘制。按钮底色与悬停态保持轻量，文件对话框外圆角为 8px。

公共 `TosAppShell` 只提供标题栏和 main 内容区，默认在标题栏右侧预留 180px。标题和可选图标在左侧，简短附加内容随标题排布；长标题使用省略号。内容在桌面独立滚动，620px 以下使用整页滚动。分栏和底部业务状态由应用实现。通用操作图标统一使用 Lucide，1.6px 线宽、随控件文字着色；品牌图标使用应用提供的资源。


`TosFileDialog` 为 NAS 文件和文件夹提供打开、保存四种模式，沿用紧凑系统字体、蓝色选择态和现有浅深主题变量。采用桌面文件浏览器的布局：顶部标题、导航与地址栏，中间共享文件夹侧栏和详情列表，底部名称、文件类型及确认/取消操作。面向 960×600 应用区域，桌面对话框宽度上限 840px、内容高度上限 540px，并随视口收缩；文件列表独立滚动。

侧栏展示 provider 返回的真实可访问共享文件夹。后退、前进、上一级、面包屑和可编辑绝对路径共同提供定位；目录内名称筛选位于工具栏。详情列表显示名称、修改日期、类型和大小，缺少可选元数据时显示破折号。单击选择行，多选模式支持 Ctrl/Meta 切换和 Shift 连续选择；方向键移动，Enter 打开目录或确认文件，双击进入目录或确认文件。导航、名称筛选和文件类型切换清空选择，保留已输入的保存名称。

主对话框与同名目标确认均使用原生模态 dialog。确认层显示完整目标路径，初始焦点位于取消；取消或 Escape 返回文件对话框，保留名称和选择，焦点回到主要操作。加载、空目录、错误、校验及已选数量均有文字状态。720px 以下隐藏修改日期；620px 以下隐藏侧栏和其余元数据，控件及文件行高为 44px，目录行提供单独的触摸进入按钮，地址栏保留可见的路径编辑入口。

人工复核文件对话框时覆盖四种模式、单选与多选范围、共享根与导航历史、面包屑和路径输入、键盘操作、空目录和权限失败恢复、筛选后选择与保存名称状态、长名称、非法名称、同名目标确认/取消、Escape 关闭和焦点恢复。分别检查中英、浅深主题、960×600 应用区域及窄屏；真实 NAS 接入还需核对 provider 的用户权限和实际写入时的冲突处理。


`TosPathInput` 在同一边框内组合路径文本框与右侧文件夹图标按钮，沿用输入框颜色、4px 圆角和可见焦点。`editable=false` 时只读文本仍可复制，选择按钮可用；`disabled` 同时禁用两者。桌面控件高 32px，窄屏高 44px；长路径在输入框内水平滚动，不撑宽布局。对话框确认后写回单个路径，取消保持原值。
